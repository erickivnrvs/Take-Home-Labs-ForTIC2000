## About this project
This project is aimed at using the C2000 Launchpad Development kit, as well as Matlab/Simulink to solve an applied problem of Control Theory to strenghten all concepts into an application for a better understanding on how the theory can be applied to an actual problem.


## About this repository
The purpose of this repository is to keep all relevant information and documentation into a single place for anyone interested.
To better understand all the underlying theory of this project some previous knowledge is required, such as:
* Usage of Terminal Windows
* Microcontrollers architecture and programming
* C/C++ programming
* Use of hardware and development boards
* Matlab scripting and Simulink modelling
* Control Theory key concepts
